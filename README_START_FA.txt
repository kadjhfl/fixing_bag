راهنمای نسخهٔ اصلاح‌شدهٔ HAWRAZ

1) برای GitHub Pages، فایل‌های داخل همین پوشه را در ریشهٔ مخزن قرار دهید؛ پوشهٔ HAWRAZ_OFFLINE را به‌عنوان زیرپوشهٔ سایت قرار ندهید.
2) در GitHub: Settings > Pages > Deploy from a branch > شاخهٔ اصلی (main) > /(root) را انتخاب کنید.
3) بعد از انتشار، یک‌بار با Ctrl+F5 بارگذاری اجباری انجام دهید. نسخهٔ Service Worker تغییر کرده تا کش قدیمی کنار گذاشته شود.
4) قبل از تعویض نسخه، از داخل برنامه فایل پشتیبان JSON بگیرید. اطلاعات فعلی در IndexedDB همان مرورگر/دستگاه ذخیره می‌شود و خودکار به GitHub یا دستگاه دیگر منتقل نمی‌شود.

اصلاحات این بسته:
- حفظ نسخهٔ سالم app.js از بستهٔ پایه؛ تابع تاریخِ تکراری/خراب‌شده وارد نشده است.
- چیدمان فرم تنظیمات در عرض کم و بزرگ‌نمایی انعطاف‌پذیرتر شده است.
- دکمهٔ ذخیرهٔ فرم هنگام پیمایش فرم در دسترس می‌ماند.
- لوگوی جدید و کش نسخهٔ جدید Service Worker اضافه شده است.

آزمون‌های انجام‌شده: بررسی نحوی JavaScript و Service Worker با Node.js، بررسی فایل‌های بسته و JSON بودن manifest. آزمون کامل تعاملی در مرورگر واقعی هنوز انجام نشده است؛ پس از انتشار، فرم تنظیمات، تاریخ شمسی/قمری/میلادی، چاپ فاکتور، پشتیبان‌گیری و بازیابی را بررسی کنید.
